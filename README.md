# Data Center Site Selection Model & Dashboard

Weighted scoring model ranking six US metros (Dallas-Fort Worth, Seattle/Quincy, Columbus, Phoenix, Northern Virginia, Hillsboro/Portland) for a 50-100 MW hyperscale deployment, with sensitivity analysis and a recommendation memo.

- **Live dashboard:** https://nafkarim.github.io/dc-site-selection/
- `DC_Site_Scoring_Model.xlsx` - 18 variables x 7 categories, six weighting scenarios, sensitivity sweeps, sources
- `DC_Site_Recommendation_Memo.docx` - recommendation, assumptions, risks, open questions for Legal / Finance / Engineering
- `build_dashboard.py` + `dashboard_template.html` - build the dashboard from the workbook (needs `openpyxl`) and check it reproduces the workbook's scores

Public data as of 7 Oct 2026. Portfolio analysis, not investment or legal advice.
